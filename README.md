Gestão de Salão
- Aplicação desktop em Python para gerir clientes, serviços e marcações de um salão de beleza, facilitando a organização diária e reduzindo erros de agendamento.

Funcionalidades
- Cadastro, consulta e eliminação de clientes
- Cadastro, consulta e eliminação de serviços
- Criação, consulta, conclusão, cancelamento e eliminação de marcações

Stack Técnica
- Linguagem: Python 3.x
- Paradigma: Programação Orientada a Objetos (POO)
- Armazenamento: SQLite
- Dependências: Tkinter (incluída no Python em instalações padrão)

Arquitetura
- O ficheiro main.py inicia a aplicação. A classe Database cria e abre a base SQLite, os repositórios implementam as operações de dados e a classe SalaoApp organiza a interface gráfica, validações e eventos Tkinter.


Execução
1. No terminal, entre na pasta do projecto.
2. Execute: python main.py
